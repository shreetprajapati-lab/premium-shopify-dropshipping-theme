# pickNbuy — Premium Shopify Dropshipping Theme

A custom, mobile-first Shopify theme for **pickNbuy**, inspired by the supplied visual reference while keeping an original brand identity and UX.

## Included
- Premium sticky header + announcement strip
- Smart expanding search UI
- Category navigation
- Editorial hero section
- Trust/value strip
- Shopify-powered collection/category cards
- Flash-deals presentation with countdown UI
- Reusable product cards with sale pricing, wishlist state, quick add and quick view
- Personalized discovery modules
- Premium newsletter capture using Shopify customer form
- Product page with gallery, variants, quantity, Add to Cart and real Shopify checkout flow
- Collection sorting
- Cart page with live Shopify cart endpoints
- Responsive mobile bottom navigation
- Scroll reveals, hover micro-interactions and reduced-motion support
- Editable accent/background/text colors and free-shipping threshold in Theme Settings

## Shopify setup
1. Upload the repository as a Shopify theme or use Shopify CLI.
2. Create the collections referenced by the navigation (Deals, New Arrivals, Best Sellers, etc.) or change those links in `sections/header.liquid` and `templates/index.liquid`.
3. Add your real products and images in Shopify Admin.
4. Configure payments, shipping, taxes, policies and checkout in Shopify Admin.
5. Add a genuine review app if you want review data displayed; the theme does not invent reviews or store statistics.
